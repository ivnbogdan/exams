# exams.ro — notes for agents

Read `docs/PLAN.md` before doing anything. Section 2 lists decisions that are final.
`docs/HUMAN-ACTIONS.md` lists what only the owner can do; if a step needs one of those, stop and ask.

## Data model in one breath
`course` (name, slug, year, level) has many `subject` (professor, exam_year, session, series,
group_name, content_html, content_text, poster_name, hidden, created_at) has many `attachment`
(original_name, storage_key, web_key, thumb_key, mime, size, width, height, kind, sort_order).
Schema lives in `src/db/schema.ts`; queries only in `src/lib/queries.ts`; DB client in `src/lib/db.ts`.

## Rules
- Content is generated by `scripts/seed.ts` from `EXPORT_DIR`. Never hand-edit content, never
  commit data, dumps, images or `.env.local`.
- Database access only in server components, route handlers and scripts. No request-time DB
  access in v1; pages are generated at build.
- Render `content_html` only; it is sanitised at import. Never render raw export text.
- Images from R2 use plain `<img>` with stored width/height, not `next/image` optimisation.
- Next.js here is 16.x. Its bundled docs in `node_modules/next/dist/docs/` win over memory.

## Commands
`pnpm dev`, `pnpm build`, `pnpm lint`, `pnpm typecheck`, `pnpm db:generate`, `pnpm db:migrate`,
`pnpm db:studio`, `pnpm seed [--dry-run] [--only-db] [--only-media]`.

## Environment variables
See `.env.example`. `DATABASE_URL`, `R2_*`, `NEXT_PUBLIC_SITE_URL` on Vercel; `EXPORT_DIR` local only.
